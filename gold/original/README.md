# Original gold artifacts

These files are the notes and scripts produced while scoring the two closed-book
rounds on 2026-11-11 (Asia/Shanghai). They are kept for provenance.

Please use the official answers in `gold/answers.md` and the verifier
`gold/compute_math.py` for scoring. Two corrections to the round-1 notes are
documented in `gold/CORRECTIONS.md`:

- `answers_round1.md` lists M2 as 6545. That count treats same-color balls as
  distinguishable. The prompt says they are indistinguishable, so the official
  gold is 10.
- `answers_round1.md` has an arithmetic typo in the M11 counterexample
  (the counterexample n = 40 is still valid; the intermediate arithmetic was
  wrong).

`round2_scores.md` is a contemporaneous score sheet. A private documentation
URL was removed from this public snapshot.
